# Checklist before calling a release stable

Use a second Apple silicon Mac with LUNA, and copies of non-private Logic projects.

- [ ] Install the .lunaaddon by opening it; the window appears in LUNA's Add Ons menu.
- [ ] "Get the helper installer" shows the .pkg. Note exactly what macOS asks.
- [ ] After installing, "Yes" unlocks step 2 and shows the helper's location.
- [ ] Log out and in: the helper starts by itself.
- [ ] Both project pickers and the output picker open and can be cancelled.
- [ ] Export a project in ~/Music or ~/Documents; note any macOS permission prompt.
- [ ] The new session is saved in the chosen folder.
- [ ] Sends (level, pre-fader, mute), mute, solo and a bypassed plug-in match in LUNA.
- [ ] MIDI notes, controllers, pitch bend and volume, pan and plug-in automation match.
- [ ] "Copy this version" and "Save both as file" work inside LUNA.
- [ ] Delete the export folder; reopen the session; all audio still plays.
- [ ] Update over an installed version; the helper reconnects.
- [ ] Uninstall; the helper folder, login item and key are gone.
- [ ] Try installing from the GitHub repository address.
