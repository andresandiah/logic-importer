1 Before proceeding, install the helper

The helper is a small Mac app that reads your Logic project. You install it once, and it starts by itself when you log in. It is included with this Add On. Needs a Mac with Apple silicon.

Shows Logic Importer Helper.pkg in Finder.
  1. Double-click Logic Importer Helper.pkg and follow the installer. It asks for your Mac password.
  2. If macOS says it cannot verify the installer: open System Settings > Privacy & Security, scroll down, click Open Anyway.
  3. Come back here and answer below.

Save your project in Logic, then choose the project (.logicx) or the folder that holds it. The project is only read. Third-party plug-ins in it are loaded one at a time to read their settings.

3 Choose the output folder and import

A new LUNA session is created in the folder you choose. Sessions you already have are not edited. LUNA switches to the new session, so save your current one first. Keep this window open until the import finishes.
