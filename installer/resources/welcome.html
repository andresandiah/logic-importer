This installs the Logic Importer helper. The Logic Importer Add On in LUNA uses it to read your Logic Pro projects.

  • It starts automatically when you log in.
  • It only accepts connections from this Mac, from the Add On.
  • It only reads Logic projects you choose.

It is installed in /Library/Application Support/Logic Importer. An uninstaller is placed there.

Requires a Mac with Apple silicon.
